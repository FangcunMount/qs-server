## 4. 当前规则、剩余事项与事实入口

### MC-R001：独立 Questionnaire 不应创建空壳 Assessment

新写冻结独立问卷或完整测评 Admission；独立问卷基础计分后结束，历史无法分类事件明确失败，不新建空壳 Assessment。

保留已有关闭结论；历史无 Admission 命中与空壳数据只能凭具名盘点决定退出，不自动删除兼容路径。

事实入口：[assessment intake](../../../internal/apiserver/application/journey/assessmentintake/service.go)、[unbound intake test](../../../internal/apiserver/application/journey/assessmentintake/service_test.go)、[已发布模型准入与执行输入](./31-关键链路-已发布模型准入与执行输入.md)。

### MC-R002：补齐 NormSubject 并修正人口学匹配语义

NormSubject 按 Assessment 时点从 Actor/Testee 物化；未知年龄与零月龄区分。Behavioral/Cognitive 共用完整 Norm runtime mapper。

待当前 checkout 环境 smoke；核对人口学分层、StandardScore、精确 NormReference 和报告，不用历史生产样本升级当前验收。

事实入口：[Norm lookup](../../../internal/apiserver/domain/calculation/norm/tables.go)、[Evaluation input contract](../../../internal/apiserver/port/evaluationinput/input.go)、[常模资产与校准](./24-核心设计-常模资产与校准.md)。

验收或重新启动条件：

- 在当前目标环境用新答卷完成 cognitive SPM smoke，核对 StandardScore、精确 NormReference、current ReportInput 和报告；历史 behavioral smoke 只作为已记录证据。
- 年龄下界/上界、性别、缺人口学信息及 generic fallback 的 golden 与 Import→Publish→Input→Calculation→Outcome 保真契约持续通过；结果能追溯常模版本与人群层。

### MC-R003：在发布时强制 behavioral_rating 的常模语义

### MC-R004：统一 DecisionResult、ScoreRange 和 OutcomeCode

DecisionResult、ScoreRange 与 OutcomeCode 已有严格结构/边界校验，结果由 Evaluation 提交，Interpretation 只查冻结文案。

保留待环境验收；逐 family 验证阈值端点、OutcomeCode/label、缺结果拒绝和报告消费，不从单一量表推断全 family。

事实入口：[min,max)`；**仅末段**可设 `max_inclusive` 或 `unbounded_max`；拒绝重叠/空洞/非末段端点标志；
- 运行时匹配同源：`conclusion.MatchBounds` / `MatchScoreRangeOutcomes`（无显式端点标志时，旧 snapshot 末段 max-inclusive 兼容）；
- scale 运行时不再用硬编码绝对分阈值兜底风险等级（无规则命中 → `none`）；
- interpretation current path 只接受 OutcomeCode→冻结 Assets；不再 score-range rematch、生成 soft default 或用 RiskLevel 替代 OutcomeCode；
- `outcome.DecisionResult` + `DecisionResultFromExecution` 落地；cognitive `AbilityConclusion.Primary`（或 `Role=total`）提升为 `Execution.Level`；
- 临界值 golden：validate endpoint、ability boundary/unbounded、interpretation no-fallback、scale/norm Matches。

Score fact
  -> DecisionSpec
