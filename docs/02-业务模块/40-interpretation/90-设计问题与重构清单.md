### IR-R023：Preview 与生产共享纯解析机制

Preview与生产共享Registry/纯解析机制；Preview不建立Generation/Run是正确边界。

保留已有关闭结论；新Builder/模板应补Preview与生产同输入同内容契约。

事实入口：[modelcatalog preview](../../../internal/apiserver/container/modules/modelcatalog/preview/)、[rendering/registry.go](../../../internal/apiserver/domain/interpretation/rendering/registry.go)。

### IR-R024：将 gRPC 名称迁移为 Outcome 驱动语义

canonical RPC为GenerateReportFromOutcome；旧GenerateReportFromAssessment只保留具名兼容观察，不代表读当前Assessment生成。

保留兼容观察；2026-09-05是历史观察计划，经过日期不自动授权删除。需当前调用方/指标为零及明确退役批次。

事实入口：[interpretation.proto](../../../api/grpc/proto/interpretation/interpretation.proto)、[interpretation_automation.go](../../../internal/apiserver/transport/grpc/service/interpretation_automation.go)。

验收或重新启动条件：

- canonical RPC 只接受 committed Outcome；Worker、重试事件与人工操作统一 OutcomeID。旧 RPC 当前调用量可观测且归零后，另立退役批次。
- proto/generated code、相关 OpenAPI/文档与日志同步；迁移期保持旧调用方兼容，不因2026-09-05已过去自动删除。

### IR-R025：在多报告出现前重新定义 Catalog Identity

当前Catalog按Assessment选择一个当前报告，尚无多ReportType/多当前版本并存契约。

待业务验收：报告类型、版本、latest/指定选择、幂等键与历史查询语义；不得先加多行索引覆盖旧协议。

验收或重新启动条件：

- 业务决定 ReportType 表示 Audience、内容形状还是产品 SKU，各类型 current version、指定历史版本查询、新发布是否重生成，以及患者/医生是否独立 Artifact。
- 出现第二种真实并存需求后再启动；Catalog Key/current selector/version query 分开，报告互不覆盖，ReportType 不绕过授权/Audience，旧单行 Catalog 有明确 migration。

### IR-R026：用真实业务定义 Audience Section Matrix

当前可控Section主要是ModelExtra，未知Audience/Section fail closed，角色差异不足以表达任意敏感章节。

待真实患者/家长/医生/运营需求和业务矩阵；确定章节、角色、组织/关系边界后再扩展。

验收或重新启动条件：

- 出现真实章节差异、医疗/合规约束或当前单 Section 无法表达需求时启动；患者/家长目前无独立观察者关系语义，不能预设角色矩阵。
- 每个 Section 有业务理由、默认值和 owner；未知默认拒绝；Actor 授权和 Audience 分层，跨角色章节矩阵有契约测试。

### IR-R027：按真实报告差异演进 Norm 与 Task Builder

NormProfile/TaskPerformance具有独立机制身份，但仍复用FactorScoring内容结构。

待真实报告差异；常模说明、分布、任务正确率/反应时/阶段等需求出现后扩专属Builder，不污染统一Executor。

事实入口：[Interpretation 模块导航](./README.md)、[领域模型](./10-领域模型.md)、[统一报告生成模型](./20-核心设计-统一报告生成模型.md)、[冻结输入、Builder 与模板路由](./21-核心设计-冻结输入、Builder与模板路由.md)、[状态、幂等、重试与可靠提交](./22-核心设计-状态、幂等、重试与可靠提交.md)、[报告成品、版本与数据一致性](./23-核心设计-报告成品、版本与数据一致性.md)、[AI 解读核心设计](./25-核心设计-AI解读.md)、[当前责任与验收边界](./25-核心设计-AI解读.md)。

验收或重新启动条件：

- 常模图/百分位/人群解释、反应时/正确率/速度准确率权衡成为一等章节，或统一 Dimension 无法无损表达且 Preview/客户端 UI 已有需求时再拆。
- 新 Content schema 明确版本，旧报告按旧 schema 读取；Builder 不复制 Generation/Run/Committer，同类新模型通过配置接入。
